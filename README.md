# Monish Balusu — Portfolio

Next.js personal site with a **CEO view / engineer view** toggle for internships and AI systems work.

## Live story this repo tells

- CoSchool — multi-agent validation (time 2 min → 40s)
- CoSchool QA — Selenium / Postman / regression
- Innerscore — instructional design & prompt work

## Run

```bash
npm install
npm run dev
```
